This folder contains helper scripts and examples pulled from NVIDIA NeMo (r2.6.0).

Files are downloaded on demand via `fetch_nemo_examples.sh` which fetches the
raw files from the official NeMo repository. These are provided as reference
launchers/config helpers for training and slurm orchestration.

Files fetched:
- `speech_to_text_finetune.py`
- `nemo_run_helper.py`
- `slurm_example.sh`
